# Labeling Spec v1 (FROZEN)

이 문서는 **동결 대상**이다. 라벨링 중 수정 아이디어가 떠올라도 고치지 말고 별도 메모로 모았다가 v2에서 반영한다.

## 클래스 정의 (4개)

각 클래스는 "단일 물체"로 정의한다. 기능이나 공정 개념(nip, tangency 등)으로 쓰지 않는다. 판별 질문에 예/아니오로 답할 수 있어야 한다.

| 클래스 | 물체 | 판별 질문 | 근거 소스 |
|---|---|---|---|
| electrode_roll | 검은 코팅면 + 구리/알루미늄 스트라이프가 있는 감긴 롤 | 원통에 감긴 전극이 보이는가 | v1, v4, v5, v15, v17 |
| prismatic_cell_tray | 각형 셀이 정렬된 트레이/컨베이어 구간 | 같은 모양 각형 셀이 2개 이상 나란한가 | v10 |
| pouch_cell_tray | 파우치 셀이 격자로 놓인 검은 트레이 | 트레이 위에 파우치가 2개 이상 있는가 | v1 |
| mixing_tank | 스테인리스 믹싱 탱크 본체 | 원통형 탱크 몸체가 보이는가 | v1 |

## 박스 규칙

1. 박스는 대상 물체의 보이는 외곽에 밀착한다
2. 웹(주행 중인 전극/포일)을 담으려고 박스를 늘리지 않는다. 물체 안에 걸쳐 있으면 자연히 포함되는 것은 무방
3. 레터박스(검은 여백)와 자막 바는 박스에 넣지 않는다
4. 주변 프레임, 가이드 롤러, 배관은 포함하지 않는다

## 스킵 기준

- 대상 물체의 면적이 프레임의 3% 미만이면 스킵
- 물체가 절반 이상 가려지면 스킵
- 판단이 3초 이상 걸리면 스킵 (애매한 것은 치지 않는다)
- 스킵은 실패가 아니다. 라벨 가능 프레임이 전체의 15%여도 정상이다
