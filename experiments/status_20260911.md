## 5. 문제와 해결

| 문제 | 진단 · 대응 |
|---|---|
| 1차 mAP 0.995인데 실사 안 됨 | 원인 4개 수치 특정: (1)라벨 기준(박스 30%가 검은 여백 20%+), (2)실사 단일 영상, (3)val 9~16장, (4)합성 이미지 36~72%. → 4클래스로 축소·영상 단위 분할·합성 전면 배제·설비 윤곽 밀착 |
| 좌표 버그 가설 | 클리핑 후 박스 면적 84% 유지 → 좌표 아니라 라벨 기준 문제로 확정 |
| train/val 누수 가설 | base 이름 검사 결과 0건 → 오답 판정 |
| YouTube 다운로드 signature/PoT 벽 | WSL yt-dlp 실패 → cobalt.tools 웹 다운로더 또는 Windows + Deno + `--cookies-from-browser chrome` 우회 성공 |
| 이름-실물 불일치 (coating_extra 폴더에 slurry tank/이송/원경) | Roboflow 배치 하나로 통합, 라벨링 시 skip 자유, 파일명 prefix로 사후 분할 |
| 소스별 실 매칭율 낮음 | 진단으로 v1_coat_a (11.6%), v4_hmhH chapter (6.5%), v1_frame_a (4.3%) 3소스 소각. train 597→415 (30.5% 감축) |
| winding_core 정의 부적합 | "심축만" → winding station (심축 + tangency + 이송 필름) 재정의. v16 원경 프레임 excluded, 라벨 예시 재작성 |
| roll_press 오탐지 우려 (idler/dancer/rewind roll) | thickness gauge 대안 조사 → v1_source 단독 소스라 test 커버 불가 확인 → 원안 유지 검토 중 (미확정) |
| coating_die 자원 고갈 | Xiaowei/LG엔솔 shorts 스크러빙 결과 대부분 원경·완제품 → 신규 다운로드 6개 (s1, s2, s19, s20, v9, v20) 편입으로 +109장 순증 |
